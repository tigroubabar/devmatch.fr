# DevMatch.fr

Le site est une application React construite avec Vite.

```powershell
npm.cmd install
npm.cmd run dev
```

La version de production se génère avec `npm.cmd run build` et se prévisualise avec `npm.cmd run preview`.

## Provenance React Bits

Les composants `SplitText`, `Magnet` et `SpotlightCard` sont issus des variantes officielles JS-CSS du dépôt [DavidHDev/react-bits](https://github.com/DavidHDev/react-bits), récupérées le 20 août 2026. Les adaptations locales se limitent au respect de `prefers-reduced-motion`, à la désactivation de Magnet sur pointeur grossier, aux identifiants sémantiques et aux couleurs sobres DevMatch.
